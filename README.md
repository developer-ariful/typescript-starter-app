# Typescript Starter Project App

A practical Node.js and TypeScript starter project demonstration TypeScript fundamental, reusable utilities, unit testing, and Git workflow.


## Feature
- TypeScript with strict type checking
- Node.js ES Modules
- Product type definition
- Product name validation
- Discount price calculation
- Unit testing with vitest
- Test coverage reporting

## Tech Stack

- [ ] NodeJS
- [ ] Typescript
- [ ] tsx
- [ ] Vitest
- [ ] V8 Coverage Provider

## Installation

Clone the repository:
```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd typescript-starter-app
```

npm install
```bash
npm install
```

## Available Commands

| Command | Description |
|---|---|
| `npm run dev` | Run the application |
| `npm run typecheck` | Check TypeScript types |
| `npm run build` | Compile TypeScript |
| `npm start` | Run compiled JavaScript |
| `npm test` | Run unit tests |
| `npm run test:watch` | Run tests in watch mode |
| `npm run test:coverage` | Generate coverage report |
| `npm run check` | Typecheck, test, and build |

## Project Structure

```text
src/

  utils/
```

## Testing

Run all tests:

```bash
npm test
```

Generate coverage report:

```bash
npm run test:coverage
```

The HTML report is generated in the `coverage/` directory.

## Learning Objectives

This project was created to practice TypeScript project setup, configuration, reusable functions, unit testing, test coverage, and Git version control.
